# OWAD 2026 claims ledger

Every numeral written in digits in `docs/manuscript/owad2026/The_Blind_Spot_Paradox_ICDM_OWAD_2026.tex`, the
paper as published at the ICDM 2026 OWAD workshop, traced to the committed artifact that carries it.
`tests/test_owad_claims.py` re-reads every artifact named below.

Columns: row ID; section label and line of the sealed `.tex`; the claim as printed; the artifact and
the field read; the value re-read from that artifact; the status.

| Status | Meaning |
|---|---|
| MATCH | The artifact value equals the printed numeral within half a unit of its last printed digit. |
| ANALYTIC | The numeral follows from a formula or a library default, which the test evaluates. |
| PROVENANCE | The value is traced, but to an artifact other than the one the text cites. |
| MISMATCH | The artifact value differs from the printed numeral beyond that tolerance. |
| AMBIGUOUS | The numeral holds under one reading of the artifact and not under another. |
| UNTRACED | No committed artifact carries the value. |
| LAYOUT | A presentation edit or rendering with no committed source. |
| QUALIFICATION | A committed measurement that qualifies a printed claim without contradicting it. |

Not ledgered: numerals that belong to a formula or a definition (exponents, indices, `c - 1`,
`{0, 1}`, `M F(s) > 1`, the constants of the propositions), the reference trigger
`\IEEEtriggeratref{17}`, the bibliography file name, and the pointer to Table 2 of Souza et al.
The table bodies are covered by M23 and M30, their captions by L01 and L02.
