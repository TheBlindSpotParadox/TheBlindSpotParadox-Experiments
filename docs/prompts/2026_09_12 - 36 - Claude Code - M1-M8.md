### 1.2 Modifications complémentaires requises

**M1 — La revendication causale du résumé contredit `S6_causal_evidence.md`. Priorité haute.**
Le résumé énonce : *« we trace this blind spot phenomenon to a single root cause---internal ADWIN hyper-reactivity »*. S6 mesure que 99,3 % de l'effacement est produit par l'apprentissage incrémental des `M−1` arbres survivants ; le bras `frozen`, qui n'apprend pas, n'efface pas ; le bras `no_swap`, qui n'échange plus, efface. L'hyper-réactivité d'ADWIN fixe **l'instant d'amorce**, pas le mécanisme d'effacement. « Single root cause » est faux dans les deux lectures. Un reviewer qui ouvre le dépôt trouve la contradiction en une lecture. Formulation correcte disponible : l'hyper-réactivité interne fixe l'amorce, l'apprentissage incrémental produit l'effacement, les échanges ultérieurs agissent en verrou décisionnel terminal.

**M2 — Deux définitions incompatibles de `τ_ARF` coexistent.**
`docs/manuscript/articleA_blindspot_v64_camera_ready.tex` porte encore `def:tau_arf` inline (premier échange d'arbre) dans `sec:race` ; `docs/manuscript/sections/framework_v2.tex` porte `def:times` avec `τ_erase`. Les sections v2 sont délibérément orphelines. Tant que l'assemblage n'a pas eu lieu, tout patch appliqué aux sections inline `sec:race`, `sec:hydra`, `sec:starvation`, `sec:decoupling` sera perdu ou dupliqué. C'est le mécanisme exact qui a fait patcher v63 pendant que v64 vivait, transposé au niveau section. **Conséquence directe sur S2 et S3** : leur périmètre d'écriture doit exclure ces quatre sections inline.

**M3 — `p_0 = 0.05` survit dans `transfer_S1.md` alors que la mesure donne 0.024.**
A1 a recalculé à `δ_P = 0.01` en conservant `p_0 = 0.05`. Les tables S6 donnent `p0_hat_median = 0.024` sur les 20 magnitudes. `θ*` et les trois `ARL₀` restent donc faux d'un facteur qui n'est pas celui corrigé. C'est la première tâche de S2 et elle est inchangée.
