## Manuscript of record

Title, since stream S11-b: **The Calibration Blind Spot: Sizing Cumulative Drift Monitors
Against Adaptive Classifiers**. It carries the term the body defines — `sec:blindspot`,
`def:blindspot` and contribution (C1) — which closes the title/body disjunction action A8 had left
open. The A8 title, *When Adaptation Erases the Evidence: Detectability Limits of Drift Monitors
Coupled with Adaptive Classifiers*, and the earlier *The Blind Spot Paradox: When Adaptive
Classifiers Defeat Drift Detectors* are revoked.

**`docs/manuscript/articleA_blindspot_v65_mlj.tex`** (class `svjour3`, target *Machine
Learning*; bibliography `docs/manuscript/articleA_biblio_v64.bib`) is the living manuscript of
record, together with the `docs/manuscript/sections/*_v2.tex` fragments it `\input`s. Every
reconciliation against `results/`, every numeral correction, and every compile check targets
these files and no other.

**Never read the state of this project from the PDF.** The compiled PDF
is a build artifact: untracked since action A5, matched by `.gitignore`, regenerated by
`tectonic` and therefore not byte-reproducible. It stays on disk, so a filesystem or
project-memory index can still serve it — and an index refreshed less often than the source hands
back a manuscript from before A1–A10, with the revoked title and the retracted abstract. This
already happened once, at the level of the whole document, and action A4 exists because of it. The
`.tex` is the state; the PDF is a rendering of whatever the source said when someone last
compiled.

`docs/manuscript/CURRENT` carries that filename, and is the one place a tool should read it
from — do not hard-code the name in a new script. `tests/test_manuscript_integrity.py::`
`test_current_manuscript_is_unique_and_live` enforces the pointer: it fails if `CURRENT` is
missing or names a file that does not exist, if a stray `.tex` appears at the repository root,
or if a second compilable manuscript enters `docs/manuscript/` without being declared in that
test's `ARCHIVED_MAIN_TEX`. Renaming the manuscript means editing `CURRENT`, not the tests.

`docs/manuscript/articleA_blindspot_v64_camera_ready.tex` is **archived** since stream S11-b:
retained for lineage, because the debt register and every transfer document are written against
it. It is declared in `ARCHIVED_MAIN_TEX`, and it is not compiled and not edited beyond the three-line
header that labels it as superseded and unsubmitted (re-pinned in the test). v63 is referenced
by older reports but is not in the repository. Line numbers quoted in reports predating S11-b
refer to v64 and do not transfer to v65; re-grep before anchoring an edit.

## Write perimeter

Action A3 settles this, and it is settled for every later stream: the agent has full write
authority over every file of this repository without exception — `run_all.sh`, the
`run_experiment_R*.sh` wrappers, `README.md`, `config/`, `tests/`, `docs/` — whenever coherence
with the active specification requires it. No file is immutable by category.

The reason is empirical. Actions A1 and A2 each found a file left stale precisely because it was
treated as untouchable or simply unowned: `README.md` still described R8 as a `lambda_op`
calibration three streams after the manuscript withdrew the estimator, and
`docs/manuscript/figures/Fig_R1_race_condition.png` had drifted from its pipeline render without
any run reproducing it. Immutability did not protect those files, it exempted them from
reconciliation.

Integrity is carried by the test suite and by traced baseline deviations, not by immutability.
Every change to an artifact under `results/` is declared in
`results/audit_S7/_baseline/authorized_deviations.txt` with its motive and measured effect, and
`sha256sum -c` against the frozen reference is the acceptance gate.

### The v65 assembly, and the guards it leaves

Stream S11-b assembled v65, and the exclusion of the four inline subsections `sec:race`,
`sec:hydra`, `sec:starvation` and `sec:decoupling` expired with it. They were merged, not
deleted: 25 labels are defined there and 30 references resolve to them. `framework_v2.tex` now
carries the vocabulary (`def:times`, `def:budget`, `def:requirement`, `def:blindspot`); the
subsections keep their measured content under it, without the three objects it supersedes
(`def:tau_arf`, `rem:agnostic`, `rem:cf_scope`). `tau_ARF` is the first-replacement delay of
`def:times`, a lower bound on `W`, and the argmax delay of `prop:certificate` is `W_argmax`, never a
second `tau_erase`. A fix now goes wherever the material lives: the v65 file or the fragment it
inputs.

Every SEARCH/REPLACE payload of `docs/theory/transfer_S*.md` and `S10_transfer.md` is applied or
declared superseded. The guards of `tests/test_S2bis_calibration.py`, `test_S8_generality.py`,
`test_S9_coverage.py`, `test_S10_external_validity.py` and `test_S2ter_predicate.py` accept a
payload only applied `(0, 1)`, resolve a target naming v64 in the manuscript `CURRENT` names, and
declare each superseded, amended, relabelled or displaced payload by name. A displaced payload is an
applied one that a later insertion separated from its anchor (S8-2, S10-C): its count reads `(1, 0)`
as if pending, and a guard that accepted `(1, 0)` hid it — which is why none does since stream S13,
round I. A transfer document is an archive: it is not rewritten, and a defect in one is recorded by
an erratum line beside it.

`docs/editorial/debt_register.md` carries a `v65` column (`PENDING` / `PURGED` / `RETAINED`) that
`tests/test_debt_register.py` checks against the rendered manuscript; no row is `PENDING`.

## Invariants

- `config/experiment_ssot.py` is the single source of truth for experimental constants.
  A registry constant re-bound to a local literal is a regression; `tests/test_S7_consistency.py`
  fails on it without importing any experiment.
- Artifacts under `results/` are bit-reproducible. `results/audit_S7/_baseline/artifacts_sha256_pre_ssot.txt`
  is the frozen reference; a re-run that changes a hash is a defect, not an update.
- Tabular ingestion of a float join key uses `float_precision='round_trip'`. The default
  pandas C parser loses 1 ULP and silently drops join rows.
- No `.pyc` and no `logs/` content is tracked; `tests/test_S7_consistency.py` enforces the former.
